# HIIT App — Content Production Checklist

What the owner needs to produce before launch. Companion doc to `content-strategy.md` — the strategy doc explains *why*; this doc says *what* and *how many*.

Tick items as they're delivered. For any cell marked "—", no asset is needed beyond the text fields.

Asset legend:
- **VID** = short video clip (phone is fine)
- **IMG** = still image / photo
- **TXT** = written content only (title, description, etc.)
- **ICON** = simple icon / emoji / SVG

## Notes for the owner

- **Video is the bottleneck.** Everything else can be filmed / drafted in a week; the 20 workout videos are the single largest time commitment. A phone in landscape, decent daylight, one afternoon should cover them.
- **Images can come from stock** (Unsplash, Pexels) where appropriate — especially recipe plating. Originals are better but not required.
- **Text fields can be drafted with AI** and then edited for brand voice. That halves the writing time.
- **Allergen tagging is non-negotiable.** Every recipe needs allergen tags before it can ship — the app's AI meal planner uses them as a safety filter, and a mis-tag is a real-world harm risk.
- **Anything with a blank "Name" cell above can be renamed or replaced.** These are placeholder slots — swap in what fits the brand.
