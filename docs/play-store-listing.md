## Formatting notes

- Play accepts basic line breaks — **use double newlines between sections** so paragraphs stay visually separate. Play does NOT render Markdown bold / italic — the `**` in the draft above is for structure only. On paste, keep the emphasis via UPPERCASE if you want any highlight (Play does render `**text**` as literal asterisks).
- Bullet points work in Play, but the bullet character `•` reads better than `-` or `*`.
- Emojis render but read as cheap when overused. The draft above has none by choice.
